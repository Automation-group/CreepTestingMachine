Конфигурация
Приложение настраивается с помощью YAML-файла. Программа ищет файл с именем config.yaml в следующих местах (в порядке приоритета):

Текущий рабочий каталог (.)

/etc/creep-server/

$HOME/.creep-server/

Пример конфигурационного файла example.config.yaml предоставлен в репозитории. Вы можете скопировать его как config.yaml и изменить под свои нужды.

Приложение также поддерживает переменные окружения, которые имеют приоритет над настройками в файле конфигурации. Они должны начинаться с префикса CREEP и использовать подчёркивания вместо точек (например, переменная окружения CREEP_SERVER_ADDRESS переопределит параметр server.address из файла конфигурации).

Настройки
Логирование
log.level: Уровень логирования. Возможные значения: debug, info, warn или error. (По умолчанию: info)

log.format: Формат вывода логов. Возможные значения: text или json. (По умолчанию: text)

Сервер
server.address: Адрес и порт, на которых будет слушать Redis-совместимый сервер. (По умолчанию: :6380)

server.password: Пароль для команды AUTH. (По умолчанию: dddddddddd)

Эксперимент
experiment.deformation_coeff: Коэффициент деформации. (По умолчанию: 0.439822972)

experiment.data_file: Путь к файлу для сохранения и загрузки состояния эксперимента. (По умолчанию: experiment.json)

experiment.force_coefficients: Коэффициенты для формулы расчёта силы: Force = a - (b * code) - c.

a: Базовое значение. (По умолчанию: 2016.3)

b: Множитель для исходного кода датчика. (По умолчанию: 0.059543)

c: Значение смещения. (По умолчанию: 73.4)

Последовательная связь
serial.baud: Скорость передачи данных для последовательного порта. (По умолчанию: 115200)

ID устройств
Эти параметры сопоставляют ожидаемые идентификаторы устройств с их ролями.

devices.driver.id: ID устройства драйвера.

devices.indicator.id: ID устройства индикатора.

devices.forcesensor.id: ID устройства датчика силы.

devices.metakon.id: ID устройства Metakon commander.
